MILK

The main project I have worked on over the years. It is far from complete, however I intend to see it through. I began the project in June 2024, where it initially took on a more retro aesthetic. Over time, I realized I wanted something more grounded, and this was the result.

Ogre the Mountain

Ogre the Mountain was a game created for the September 2025 CTC Creative Jam. Made in only 48 hours, I was the 3D artist. I built the mountain, an NPC model, the ogre, the staff, and a few extra props, as well as the thumbnail.

SEWER GAME

This project is one I come back to every now and then, and it has a new look each time. This particular instance was the most complete, having many assets created and an entire level blocked out. It isn't perfect, but it's a good demonstration of what could be.

HOUSE GAME

This is another project I have returned to a few times, however the concept and visual identity have stayed relatively the same. I started creating it in high school, experimented with various layouts, but I never got to implement many of the mechanics. I have grown a lot as a 3D artist since then, this was my first time ever using Substance Painter, but it holds up fairly well.
